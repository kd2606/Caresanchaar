# CareSanchaar clinical dataset bundle

These CSVs are downloaded from the official Columbia DBMI and UCI repositories and formatted for research/RAG ingestion. They are not clinically validated for diagnosis, triage, or patient care, and must not be used with real patient data without appropriate governance, licensing review, de-identification, and clinical validation. See `DATASET_SOURCES.json` for source URLs, dataset IDs, archive members, row counts, and columns.
